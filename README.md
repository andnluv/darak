# 다락방 · DARAK

SillyTavern용 통합 확장입니다. 채팅 화면을 이북·영화 티켓·신문·잡지 지면으로 꾸미고, 번역·대필·QR 보관함 같은 도구를 한곳에 모았습니다. 모듈마다 따로 켜고 끌 수 있습니다.

> 베타입니다. 개발자 서버와 아이폰에서 확인했지만, 다양한 환경에서의 검증은 이제부터입니다.

## 채팅 테마 4종

디자인 모듈을 켜면 채팅 메시지가 한 장의 지면이 됩니다. 테마마다 컬러칩 4개가 있고, 글꼴·글자 크기·줄간격·자간·문단 간격·대사 색은 따로 고릅니다.

| 테마 | 컨셉 | 컬러칩 |
|---|---|---|
| **Paper** | 이북 리더 서재. 위에 표지(사진)와 NOW READING, 그 아래 책장(등록한 프로필 사진 또는 스와이프를 책등으로), 본문은 가로로 쪽을 넘깁니다. 책장은 ‘서재’ 버튼으로 접을 수 있습니다(Studio를 뺀 세 테마 공통). 책장 소품은 테마마다 다릅니다. | 상아 · 세피아 · 한지 · 로즈 |
| **Nocturne** | 영화 포스터와 티켓. 포스터형 사진, 하단의 티켓 스텁(절취선·바코드). 위에는 황동 선반 서재(필름 릴·촛대·달). | 은빛 · 골드 시네마 · 필름 느와르 · 보랏빛 밤 |
| **Porcelain** | 청화백자 신문 지면. 제호, 이중 괘선, 사진 캡션. 제호 아래 청화 서재(매병·사발·접시). | 클래식 · 로얄 · 청자 · 트림 |
| **Studio** | 잡지 화보. 위는 화보, 아래는 분리된 메시지 카드. 첫 글자 장식은 끌 수 있습니다. | 세이지 · 블루 그레이 · 피치 · 라벤더 |

공통으로 메시지마다 큰 이미지, 양쪽 정렬 본문, 대사 강조, 하단의 스와이프(‹ 1/3 ›)·토큰 수·버튼 줄이 있습니다. PC와 모바일은 배치가 같고 크기만 달라집니다. 토큰 수는 SillyTavern의 "메시지 토큰 수 표시"를 켜야 보입니다.

AI가 응답을 쓰는 동안에는 채팅 맨 아래에 테마별 ‘입력 중’ 표시(Paper 원고 줄, Nocturne 필름 프레임, Porcelain 활자 조판, Studio 지면 블록)가 뜨고, 디자인 설정에서 끌 수 있습니다.

디자인을 켜면 원래 테마의 사용자 CSS가 꺼지고, 끄면 그대로 돌아옵니다. 테마 설정 파일은 건드리지 않습니다.

## 모듈

| 모듈 | 하는 일 |
|---|---|
| 디자인 | 위의 테마 4종, 글꼴, 가독성 설정 |
| 한글화 | 추론 제목과 프롬프트 토글 이름을 한국어로 표시 |
| 번역 | AI 응답을 한국어로, 내 입력을 영어·일본어·중국어로 번역. 용어집 지원 |
| 대필 | 지금 쓰는 RP 연결로 내 캐릭터의 다음 메시지를 써서 입력창에 넣기 (자동 전송 없음) |
| QR 보관함 | Quick Reply를 세트별로 모아 실행·검색, 세트 가져오기·내보내기·백업 |
| 통합 조회 | 테마·프롬프트·확장 목록과 오류·충돌 점검, 확장 일괄 업데이트 |
| 프로필 사진 | 봇·페르소나마다 사진을 여러 장 등록하고 메시지별로 바꿔 쓰기 |
| 테마 이미지 교체 | 테마 CSS의 이미지를 내 파일로 교체 |
| 이미지 모아보기 | 현재 채팅과 서버 폴더의 이미지를 격자로 보기 (읽기 전용) |
| 모바일 최적화 | 화면 밖 메시지 그리기 건너뛰기, 효과 줄이기, 입력 시 화면 확대 방지 |

기능별 자세한 사용법은 설정 패널 안의 안내를 따르세요.

## 설치

1. SillyTavern → 확장(블록 아이콘) → **Install extension**
2. 이 저장소의 GitHub 주소를 입력하고 설치
3. 새로고침하면 확장 설정에 **다락방 · DARAK**이 생깁니다. 필요한 모듈만 켜세요.

## 알아 두세요

- **번역 확장은 하나만**: 번역 모듈을 쓰려면 Interpres 같은 다른 번역 확장을 꺼 주세요. 같이 켜 두면 같은 메시지를 두 번 번역합니다. 번역은 설정에서 번역용 연결 프로필을 골라야 하고, 요청마다 모델 사용량이 듭니다.
- **화면을 바꾸는 다른 확장·테마**와 함께 쓰면 일부 영역이 겹칠 수 있습니다. 통합 조회가 겹침을 알려 줍니다.
- **글꼴은 웹폰트**입니다. 선택했을 때만 인터넷에서 불러오고, 오프라인이면 기기 기본 글꼴로 보입니다. 제공처는 `FONT_LICENSES.md`에 있습니다.
- 대사 강조는 인용부호 기준입니다. 인용부호가 없으면 지문으로 표시됩니다.
- 설정은 SillyTavern 설정 파일에 저장됩니다. 프로필 사진은 서버의 사용자 파일, 테마 이미지 교체는 이 브라우저에 저장됩니다.
