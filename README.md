# 다락방 · DARAK

SillyTavern용 통합 확장입니다. 채팅 화면을 이북·영화 티켓·신문·잡지 지면으로 꾸미고, 번역·대필·QR 보관함 같은 도구를 한곳에 모았습니다. 모듈마다 따로 켜고 끌 수 있습니다.

## 채팅 테마 4종

디자인 모듈을 켜면 채팅 메시지가 한 장의 지면이 됩니다. 테마마다 컬러칩 4개가 있고, 글꼴·글자 크기·줄간격·자간·문단 간격·대사 색은 따로 고릅니다.

| 테마 | 컨셉 | 컬러칩 |
|---|---|---|
| **Paper** | 이북 리더. 왼쪽 표지(사진, 중간 크기)와 NOW READING, 아래에 본문. | 상아 · 세피아 · 한지 · 로즈 |
| **Nocturne** | 영화 포스터와 티켓. 가운데 큰 포스터, 아래 장면 번호·시각, 하단의 티켓 스텁(절취선·바코드). | 은빛 · 골드 시네마 · 필름 느와르 · 보랏빛 밤 |
| **Porcelain** | 청화백자 지면. 위에 이름 제호(이중 괘선), 사진은 원형 메달리온. | 클래식 · 로얄 · 청자 · 트림 |
| **Studio** | 잡지 화보. 큰 사진과 큰 번호·이름, 아래 본문. 첫 글자 장식은 끌 수 있습니다. | 세이지 · 블루 그레이 · 피치 · 라벤더 |

모든 테마가 같은 순서(사진 → 이름·번호·시각 → 책장 → 본문 전폭)로 쌓이고, 본문은 쪽 넘김 없이 위아래 스크롤로 읽습니다. 상태창 같은 블록 위젯은 카드 폭을 꽉 채웁니다.

**북마크 책장** — 메시지 아래 줄의 책갈피 버튼을 누르면 그 메시지가 책으로 꽂힙니다(다시 누르면 빠집니다). 책장은 마지막 메시지에만 보이고, 책이 많으면 가로로 밀어 볼 수 있으며, 0권이면 숨습니다. 책등에는 메시지 번호가 쓰입니다. 책등을 누르면 그 메시지로 이동합니다. ◆/◇ 버튼으로 책장을 접고 펼칩니다. 북마크는 채팅마다 저장됩니다. 책장 소품은 테마마다 다릅니다(서재·필름 릴·청화 매병·화보 작업실).

**메시지 버튼** — 메시지 아래 버튼은 앞줄에 몇 개만 두고 나머지는 ⋯ 안에 접습니다. 디자인 설정의 "메시지 버튼 고르기"에서 앞줄에 둘 버튼을 고를 수 있습니다.

**프로필 사진 크기** — 디자인 설정에서 메시지 사진을 끄기·작게·기본·크게 중에 고릅니다.

**내 글꼴** — 기본 글꼴 외에 웹폰트를 최대 20개 더할 수 있습니다. "내 글꼴 추가"에 표시명, 글꼴 이름(font-family), 주소 또는 CSS 코드를 넣으면 됩니다. 세 번째 칸에는 CSS 주소(Google Fonts 등), 글꼴 파일 주소(woff2·woff·ttf·otf), @font-face 코드를 넣을 수 있고, https 주소만 받습니다. @font-face 코드는 글꼴 이름 칸을 비워도 됩니다.

**본문 서식** — 지문과 대사에 각각 굵기(기본·얇게·보통·조금 굵게·굵게), 기울임, 밑줄(실선·점선·형광펜)을 따로 고릅니다. 굵기 '기본'은 테마 기본 그대로입니다. 글꼴이 가진 굵기만 정확히 나오고, 없는 굵기 단계는 흐리게 보입니다(고르면 가까운 굵기로 표시됩니다). `*강조*`를 기울임 + 한 단계 굵게로 구분하는 '강조 서식'도 있으며 기본은 꺼짐입니다. 밑줄을 형광펜으로 쓸 때의 **형광펜 색**은 테마 컬러의 강조색과 따로 고를 수 있고(테마마다 저장), 「강조색과 같게」를 켜 두면 예전처럼 강조색을 따라갑니다.

공통으로 메시지마다 큰 이미지, 양쪽 정렬 본문, 대사 강조, 하단의 스와이프(‹ 1/3 ›)·토큰 수·버튼 줄이 있습니다. PC와 모바일은 배치가 같고 크기만 달라집니다. 토큰 수는 SillyTavern의 "메시지 토큰 수 표시"를 켜야 보입니다.

AI가 응답을 쓰는 동안에는 채팅 맨 아래에 테마별 ‘입력 중’ 표시(Paper 원고 줄, Nocturne 필름 프레임, Porcelain 활자 조판, Studio 지면 블록)가 뜨고, 디자인 설정에서 끌 수 있습니다.

디자인을 켜면 원래 테마의 사용자 CSS가 꺼지고, 끄면 그대로 돌아옵니다. 테마 설정 파일은 건드리지 않습니다.

## 모듈

| 모듈 | 하는 일 |
|---|---|
| 디자인 | 위의 테마 4종, 글꼴, 가독성 설정 |
| 한글화 | 추론 제목과 프롬프트 토글 이름을 한국어로 표시. 「화면 전체 한국어」(기본 꺼짐)는 SillyTavern·확장 화면에 남은 영어·중국어를 번역 모델로 한 번 번역해 저장하고 화면 글자만 바꿉니다 |
| 번역 | AI 응답을 한국어로, 내 입력을 영어·일본어·중국어로 번역. 용어집, 번역 지시문(기본값/직접 입력) 지원 |
| 대필 | 지금 쓰는 RP 연결로 내 캐릭터의 다음 메시지를 써서 입력창에 넣기 (자동 전송 없음) |
| QR 보관함 | Quick Reply를 세트별로 모아 실행·검색, 세트 가져오기·내보내기·백업 |
| 통합 조회 | 테마·프롬프트·확장 목록과 오류·충돌 점검, 확장 일괄 업데이트 |
| 프로필 사진 | 봇·페르소나마다 사진을 여러 장 등록하고 메시지별로 바꿔 쓰기 |
| 화자 얼굴 | 여러 인물이 나오는 봇에서 대사 옆에 말한 인물의 얼굴 보이기 · 카드마다 얼굴 목록 등록 |
| 테마 이미지 교체 | 테마 CSS의 이미지를 내 파일로 교체 |
| 이미지 모아보기 | 현재 채팅과 서버 폴더의 이미지를 격자로 보기 (읽기 전용) |
| 날씨·분위기 | 배경 위에 비·눈·흐림·안개·뇌우와 꽃잎·낙엽·반딧불·불똥·별빛 깔기 · 채팅마다 따로 저장 · 다른 모듈과 독립 |
| 모바일 최적화 | 화면 밖 메시지 그리기 건너뛰기, 효과 줄이기, 입력 시 화면 확대 방지 |

기능별 자세한 사용법은 설정 패널 안의 안내를 따르세요.

## 설치

1. SillyTavern → 확장(블록 아이콘) → **Install extension**
2. 이 저장소의 GitHub 주소를 입력하고 설치
3. 새로고침하면 확장 설정에 **다락방 · DARAK**이 생깁니다. 필요한 모듈만 켜세요.

## 업데이트

- 확장 메뉴에서 다락방을 업데이트한 뒤 새로고침하세요. 설정은 그대로 남습니다.
- 이전 이름(태번 도구함)으로 쓰던 설정은 첫 실행 때 한 번 자동으로 옮겨 옵니다.
- 디자인 설정 내보내기 파일에는 테마·글꼴·색·본문 서식·내 글꼴·메시지 버튼 선택, 화자 얼굴 목록이 들어갑니다(얼굴 사진 파일은 서버에 있어서 다른 서버로 옮기면 다시 올려야 합니다). 이전 버전에서 내보낸 파일도 가져올 수 있습니다.

## 알아 두세요

- **번역 확장은 하나만**: 번역 모듈을 쓰려면 Interpres 같은 다른 번역 확장을 꺼 주세요. 같이 켜 두면 같은 메시지를 두 번 번역합니다. 번역은 설정에서 번역용 연결 프로필을 골라야 하고, 요청마다 모델 사용량이 듭니다.
- **디자인이 꾸미는 범위**는 채팅 메시지, 입력창, 다락방 패널입니다. 실리태번 메뉴·확장 목록·창에는 색만 맞추고 모양(테두리·칸)은 건드리지 않아서, 다른 확장 화면과 덜 겹칩니다.
- **화면을 바꾸는 다른 확장·테마**와 함께 쓰면 일부 영역이 겹칠 수 있습니다. 통합 조회가 겹침을 알려 줍니다.
- **글꼴은 웹폰트**입니다. 선택했을 때만 인터넷에서 불러오고(글꼴 목록을 열면 화면에 보이는 글꼴도 미리 보기용으로 불러옵니다), 오프라인이면 기기 기본 글꼴로 보입니다. 제공처는 `FONT_LICENSES.md`에 있습니다.
- 대사 강조는 인용부호 기준입니다. 인용부호가 없으면 지문으로 표시됩니다.
- **강조 서식**은 지문 전체를 `*별표*`로 감싸 쓰는 봇에서는 켜지 않는 편이 좋습니다. 켜도 한 문단의 지문 80% 이상이 별표로 감싸져 있으면 강조가 아니라 지문으로 보고 뺍니다.
- **지문 밑줄**을 켜면 화면에서만 지문 글자를 감싸서 대사와 구분합니다. 메시지 내용은 바뀌지 않고, 끄면 원래대로 돌아옵니다.
- **Nocturne 대사**는 자막식 배경이 이미 깔려 있어서 형광펜이 흐리게 보입니다. 고르면 그 위에 연하게 겹쳐 적용됩니다.
- **화자 얼굴**은 대사 바로 앞의 `[이름]` 표기로 화자를 찾고, 없으면 대사 앞뒤 글에 나온 등록된 이름으로 추정합니다. 화면에서만 `[이름]`을 숨기며 채팅 내용에는 남습니다. 지시문(대사 앞에 `[이름]`을 붙이라는 한 줄)은 설정에서 끌 수 있습니다. 한 글자 이름은 표기로만 인식하고, 번역문에 얼굴을 보이려면 번역된 이름을 '다른 이름'에 넣어 주세요. 대사 인식은 디자인 모듈에 의존합니다.
- **얼굴 위치**는 목록의 [위치 조정]에서 끌어 옮기고 크기를 맞출 수 있습니다. 사진 파일은 자르지 않고 보이는 위치만 저장하므로 언제든 다시 바꿀 수 있고, 표정 그림도 같은 위치를 씁니다.
- **날씨·분위기**: 설정의 「날씨 · 분위기」에서 날씨(없음·흐림·안개·비·눈·뇌우에서 흐림·안개는 한 항목)와 분위기(없음·꽃잎·낙엽·반딧불·불똥·별빛)를 고릅니다. 고른 값은 채팅마다 따로 저장됩니다. 효과는 채팅 칸 위로 지나가며(설정 창·메뉴보다는 아래), 흐림·뇌우의 화면 어둡힘만 채팅 칸 뒤에 그립니다. 휴대폰은 초당 30장·PC는 60장까지만 그리고, 탭이 가려지면 멈추며, 기기의 "동작 줄이기"나 다락방 모바일 최적화의 "애니메이션 줄이기"가 켜져 있으면 멈춘 장면만 보여 줍니다. 효과 색은 밝은 화면용·어두운 화면용이 따로 있고 기본은 테마 글자색으로 자동 판단합니다. 선 아이콘은 Lucide(ISC 라이선스)입니다.
- **화면 전체 한국어(v1.4.0)**: 한글화 모듈 안의 「화면 전체 한국어」를 켜고 번역용 연결 프로필을 고른 뒤 [화면 번역하기]를 누르면, SillyTavern 기본 한국어에 없는 영어·중국어(설정 화면·확장 설정·창·고정 알림 문구)를 200줄씩 나눠 번역합니다(처음 7회 안팎). 결과는 '영어 원문 → 한국어' 표로 설정에 저장되어 다시 부르지 않고, 새로 생긴 영어·중국어는 대기 목록에 모였다가 [대기 중인 글자 번역]을 눌렀을 때만 번역합니다(자동 호출 없음). 채팅 본문·입력칸 값·캐릭터/페르소나/프리셋/모델/파일 이름·코드·단축키는 바꾸지 않고, 알림은 숫자·이름이 없는 고정 문구만 번역합니다. 「번역 수정 목록」에서 검색해 줄마다 고치거나 [원문으로]·[제외에 추가]를 할 수 있고(고친 줄은 다시 번역해도 덮어쓰지 않음), 「이 확장 제외」로 문제 있는 확장을 통째로 뺄 수 있습니다. 끄면 화면 전체가 원래대로 돌아옵니다. 번역 목록은 전용 파일(darak-ui-translation.json, 3MB까지)로 내보내고 가져옵니다.
- **디자인 정비(v1.3.2)**: 표정 관련 창을 한 가지 창 모양으로 맞추고(입력칸은 밑줄형, 긴 안내는 「자세히」로 접기), 표정 고르기를 3열 큰 얼굴로, 얼굴 목록 줄은 아이콘 버튼으로, 흩어진 추가 버튼은 「추가」 메뉴 하나로 모았습니다. 위치 조정 창은 바깥을 더 어둡게 했습니다. 위치 조정 창의 크기 칸에는 배율을 숫자로 보여 주고, 본문 서식의 기울임 칸은 중복 문구를 정리했습니다. 디자인 설정에 필름 그레인·비네트·새 응답 등장 효과(없음/서서히/떠오르기)가 생겼고 기본은 모두 꺼짐입니다. 기기의 "동작 줄이기"가 켜져 있으면 등장 효과는 쓰지 않습니다.
- **v1.3.5 수정(효과 층 높이 0)**: 휴대폰 SillyTavern처럼 html에 변형(transform)이 걸리고 body가 고정된 환경에서는 효과 층의 기준이 높이 0인 html이 되어, 그레인·비네트·날씨가 모두 높이 0으로 그려지고 있었습니다(효과 진단으로 확인). 층에 화면 크기를 직접 지정해 고쳤습니다.
- **v1.3.4 수정(휴대폰에서 효과가 안 보이던 문제)**: 휴대폰은 입자 수를 화면 넓이에 비례해 줄이다 보니 눈이 10개 남짓밖에 안 남았고, 1배 해상도로 그려 가는 빗줄기가 뭉개졌습니다 → 작은 화면 바닥값과 2배 해상도로 고침. 필름 그레인은 섞기 모드를 빼고 밝은 화면엔 어두운 알갱이, 어두운 화면엔 밝은 알갱이로 다시 만들었고, 비네트는 어두운 테마에서 더 진하게 했습니다. 효과 층들은 아이폰(사파리 엔진)에서 흐림 처리된 채팅 칸 아래로 묻히지 않도록 별도 층으로 올립니다. 디자인 설정과 날씨 설정에 「효과 진단」 버튼을 추가했습니다(누르면 효과 층 상태를 글로 복사).
- **v1.3.3 수정**: 휴대폰에서 고정하지 않은 미리보기가 칸 밖으로 넘치던 문제, 필름 그레인·비네트가 설정 창 등에 가려 안 보이던 문제(이제 화면 맨 위에 그림, 눌림은 통과), 상단 메뉴의 월드 인포·사용자 설정·배경 아이콘이 바뀌지 않던 문제를 고쳤습니다. 날씨·분위기 효과는 이제 채팅 칸 위로 지나갑니다(설정 창·메뉴보다는 아래, 화면 어둡힘은 글씨가 흐려지지 않게 채팅 칸 뒤에 그대로). zip 가져오기 칸에 파일을 끌어 놓을 수 있고, 새 응답 등장 효과는 다락방 최적화의 "애니메이션 줄이기"에서도 꺼집니다.
- **아이콘 통일(v1.3.2)**: 상단 메뉴·메시지 버튼·입력창 버튼의 아이콘을 모두 Lucide 선 아이콘(굵기 1.5, 둥근 끝)으로 바꿨습니다. 테마마다 달랐던 굵기·끝 모양은 하나로 통일했습니다. SillyTavern 자체 설정 창 안의 아이콘은 건드리지 않습니다.
- **얼굴 크기**: 설정의 「화자 얼굴」에서 채팅 속 얼굴을 작게·보통·크게·아주 크게 중에서 고를 수 있습니다(기본 보통).
- **얼굴 가져오기**: 설정의 「화자 얼굴」에서 ① 인물 도감 같은 페이지의 코드를 붙여 넣어사진과 이름을 한꺼번에 가져오거나, ② `인물_표정.png` 꼴의 파일이 든 zip을 올려 인물마다 한 명으로 묶고 표정을 저장할 수 있습니다. 카드마다 최대 150명까지 등록되고, 이름이 30명을 넘으면 AI 지시문에는 이름 목록을 싣지 않습니다. 두 인물이 같이 쓰는 성·이름(예: 같은 성)은 화자 추정에서 빼고 `[이름]` 표기로만 인식합니다. 다른 사이트의 사진은 사이트가 허용할 때만 가져올 수 있고, 가져온 사진은 서버에 복사되니 쓸 권리가 있는 사진인지 확인하세요.
- 설정은 SillyTavern 설정 파일에 저장됩니다. 프로필 사진은 서버의 사용자 파일, 테마 이미지 교체는 이 브라우저에 저장됩니다.
